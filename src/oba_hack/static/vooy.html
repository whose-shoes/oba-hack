엄마 전화가 vooy 대화가 됩니다

자녀가 vooy에 말로 엄마를 등록하면, 엄마와 통화가 끝날 때마다 정리본이 vooy로 먼저 오고, “응 결제해” 한마디에 vooy가 자녀가 정한 범위 안에서 결제합니다. 서버는 승인·한도·차단을 지키고, 결제는 1회용 토큰으로만 넘깁니다.

1분 연결도구 보기설계 원칙
  • 도구 12개사용자가 실제로 할 말로 설명한 도구
  • 개인 MCP 주소vooy가 사용자 정보를 안 보내도 계정이 분리됨
  • 1회용 결제 토큰이 주문·이 금액·30분·한 번 — 카드번호는 넘기지 않음

1분 연결

vooy의 서비스 연결에 MCP 주소를 넣고, Recipe Studio에 레시피를 붙여 넣으면 끝입니다.

  1. MCP 주소 넣기 — 둘 중 하나를 고르세요.

    바로 개인 주소 받기 빠름

    데모 번호·엄마 메모가 채워진 체험 계정을 만들고 개인 주소를 드려요.

    vooy에서 말로 가입하기

    공용 주소를 넣고 “엄마 등록해줘…”라고 말하면 vooy가 개인 주소를 받아 와요. 받은 주소로 바꿔 넣으면 됩니다.

  2. 레시피 붙여 넣기 — vooy가 언제 어떤 도구를 부를지 정한 지침입니다.
    레시피 전문 보기
  3. vooy에게 말해 보기 — 순서대로 말하면 처음 등록부터 결제·취소까지 한 바퀴 돕니다.

왜 좋은 vooy MCP인가

말로 찾히는 도구

도구 설명에 사용자가 실제로 할 말을 넣었습니다. vooy의 도구 검색이 “응 결제해”, “그건 빼줘”, “통화 저장됐어”를 바로 맞는 도구로 잇습니다.

approve_order: "…'응 결제해', '그거 사줘', '주문해'처럼 분명히 동의했을 때…"

마지막 안전장치는 서버

상품권·사칭 의심 주문은 누가 approve_order를 불러도 서버가 거절합니다. 결제·환불 도구엔 파괴적 힌트를 달고, 설명에 “사용자가 분명히 동의한 뒤”를 명시했습니다.

approve_order(차단 주문) → {"ok": false, "message": "🚫 결제를 막은 주문이에요: 상품권은 대신 결제하지 않는 품목이에요 (보이스피싱 단골 수법). 엄마께 직접 전화해 확인해 보세요."}

위임 증서 + 1회용 결제 토큰

승인하면 상품·수량·최대 금액·배송지와 함께, 이 주문·이 금액에 30분 동안 한 번만 쓰는 토큰을 줍니다. vooy는 카드번호 없이 결제를 실행합니다.

"checkout": {"payment_token": "ptok_…", "max_amount": 59000, "single_use": true}

먼저 알려 주는 정리본

통화가 끝나면 서버가 정리본을 만들고, vooy는 웹훅(HMAC 서명)으로 받거나 5분 반복 작업으로 가져갑니다. 두 경로가 ‘전달됨’ 표시를 공유해 같은 정리본이 두 번 가지 않습니다.

get_new_parent_requests → {"has_new": false, "notify_user": false, "message": ""}

사용자마다 개인 주소

vooy는 MCP 요청에 사용자 정보를 보내지 않으므로, 계정마다 다른 MCP 주소를 발급합니다. 공용 주소는 가입만 하고, 모르는 주소는 404, 남의 주문은 건드릴 수 없습니다.

/mcp/<공용> → setup_parent만 · /mcp/<개인> → 그 사용자 데이터만

대화로 등록하고 기억

번호·배송지·엄마 건강·늘 쓰는 물건을 말로 저장합니다. 이 메모는 통화에서 부탁을 찾고 상품을 고를 때 반영됩니다.

setup_parent(note="휴지는 늘 깨끗한나라 30롤 쓰심")

바로 보여 줄 문장 + 구조화 데이터

모든 응답에 사용자에게 그대로 보여 줄 message와 다음 행동(next_action, need)을 담았습니다. 실패해도 무엇을 물어야 할지 알려 줍니다.

{"ok": false, "need": ["내 전화번호"], "message": "처음 연결이라 내 전화번호가 필요해요…"}

엄마 문자는 자식 말투로

결제가 끝나면 vooy가 자녀 말투로 쓴 문장을 엄마께 보냅니다. 비워 두면 서버가 기본 문구로 대신 보내 흐름이 멈추지 않습니다.

checkout_order(…, message_to_mom="엄마, 휴지 시켜놨어~ 내일 와!")

vooy가 웹훅을 받을 수 있다면

대시보드 설정의 ‘vooy 전달’에 주소·토큰·서명 비밀을 넣으면, 통화 처리 직후 바로 보냅니다. 실패하면 15·30·60·120초로 재시도하고, 그 사이 반복 작업이 먼저 가져가도 중복되지 않습니다.

대시보드 GitHub 모든 결제·문자는 테스트(모의)이며 실제 거래가 일어나지 않습니다.
