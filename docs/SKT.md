# 에이닷 연동 — SKT 전달용

에이닷이 통화 요약에서 찾은 '장보기 할일'을, 자녀가 정한 범위 안에서 실제 구매·결제·부모님 안내까지 끝내는 연동입니다.
결제·문자는 모두 테스트(모의)입니다.

- 체험: `https://dont-call-me-mama.fly.dev/skt` (방문하면 체험 계정이 자동으로 생김)
- 소스: https://github.com/whose-shoes/oba-hack — 연동 코드는 `src/oba_hack/telco.py`

## 1. 5분 체험 순서

1. `/skt`의 **직접 해 보기**에서 **장보기**를 고르고 **통화 종료** → 웹훅 수신부터 자녀 정리본까지 8단계가 차례로 채워집니다.
   - 휴지·계란: 늘 사던 소액이라 바로 테스트 결제 → 엄마 문자
   - 전기요: 처음 사는 상품이라 자녀 승인 대기 → **결제 승인**을 누르면 결제·문자
   - 병원 예약: 구매 외 부탁으로 자녀에게 전달
2. **사칭 · 모르는 번호** → 번호 확인 단계에서 멈추고 아무것도 저장하지 않습니다.
3. **사칭 · 엄마 번호로** → 상품권·'폰이 고장' 정황이라 결제를 막습니다. 누가 승인해도 서버가 거절합니다.
4. **알아서 골라 줘** → "니가 알아서 해줘"라는 부탁에 엄마 메모(무릎이 안 좋으심)와 평점으로 상품을 고르고 이유를 붙입니다.
5. **API로 호출해 보기**의 curl을 실행하면 에이닷 대신 직접 웹훅을 보낸 결과가 '최근 통화'와 대시보드에 나타납니다 (통신사 토큰은 별도 전달).
6. 대시보드(`/?a=…`)의 설정에서 '카드 결제 실패시키기'를 켜고 승인하면 SK pay로 복구되는 과정을 볼 수 있습니다.

## 2. SKT가 연결할 것

| 단계 | SKT | 우리 서비스 |
| --- | --- | --- |
| 동의 | 에이닷 설정에서 자녀가 '가족 부탁 위임'을 켜고 부모님 번호를 고름 | 같은 번호로 가입(또는 vooy에서 말로 등록) |
| 통화 종료 | 그 번호와의 통화가 끝나면 요약·할일·대화 텍스트를 웹훅으로 한 번 전송 | 번호 확인 → 부탁 추출 → 상품 선택 → 위임 판단 → 테스트 결제 |
| 결과 | (선택) 엄마 안내 문자를 사전등록 발신번호로 발송, SK pay 결제 | 자녀에게 정리본(vooy·앱), 엄마께 문자, 실패 복구·취소/환불 |

가장 좋은 형태는 **동의한 번호의 통화만 SKT 밖으로 나가는 것**입니다. 잘못 오더라도 서버는 등록된 가족 통화가 아니면 내용·번호를 저장하지 않고 버립니다.

## 3. 웹훅 계약

```http
POST /v1/telco/call-ended
Authorization: Bearer <통신사 토큰>
Content-Type: application/json
X-Telco-Timestamp: 1794031010                                         # 선택: 서명을 켠 경우
X-Telco-Signature: sha256=<HMAC-SHA256(서명 비밀, "<timestamp>.<본문>")>   # 선택: 서명을 켠 경우

{
  "call_id": "skt-20261117-0001",
  "from_number": "010-2345-6789",
  "to_number": "010-1234-5678",
  "ended_at": "2026-11-17T14:10:00+09:00",
  "summary": "엄마가 휴지·계란과 전기요를 부탁함",
  "todos": ["장보기: 휴지 30롤, 계란 한 판", "장보기: 전기요"],
  "transcript": "엄마: 휴지가 다 떨어졌어. 저번에 시켜준 30롤짜리 그거 좋더라.\n나: 알았어"
}
```

| 필드 | 필수 | 설명 |
| --- | --- | --- |
| `call_id` | 권장 | 통신사 통화 ID (128자 이내). 같은 값이 다시 오면 중복으로 보고 처리하지 않음 |
| `from_number` · `to_number` | 필수 | 건 사람 · 받은 사람. 방향 무관 — 자녀 ↔ 등록된 부모님 조합만 처리 |
| `ended_at` | 선택 | 통화 종료 시각 (ISO 8601) |
| `summary` | 선택 | 에이닷 통화 요약. 기록에 함께 보관 |
| `todos` | 선택 | 에이닷 '할일' (최대 20개). 부탁 추출의 힌트로 쓰고, 근거 문장은 대화에서 인용 |
| `transcript` | 필수 | 화자 표기된 통화 텍스트 (`엄마: …` / `나: …`, 5만 자 이내) |

| 응답 | 뜻 |
| --- | --- |
| `202 {"accepted": true, "call_id": "…"}` | 받았고 처리 시작 (비동기, 보통 수 초) |
| `202 {"accepted": false, "reason": "not a registered family call"}` | 등록된 가족 통화가 아님 — 아무것도 저장하지 않음 |
| `202 {"accepted": true, "duplicate": true, "call_id": "…"}` | 이미 받은 `call_id` |
| `401` | 토큰 오류, 또는 서명을 켰을 때 서명·타임스탬프(5분) 오류 |
| `422` | 형식 오류 |

처리 결과 확인 (데모 서버 전용, 통신사가 보낸 `call_id`로 조회):

```bash
curl https://dont-call-me-mama.fly.dev/v1/telco/calls/skt-20261117-0001 -H "Authorization: Bearer $TELCO_TOKEN"
# → {"status": "processed", "engine": "OpenAI", "orders": [{"product": "…", "decision": "auto", "status": "paid", …}],
#    "sms_to_mom": ["엄마, 말씀하신 … 주문했어요. …"], "digest_text": "엄마와 통화에서 부탁 4건을 정리했어요. …"}
```

서명 만들기 예 (Python):

```python
ts = str(int(time.time()))
sig = "sha256=" + hmac.new(secret.encode(), ts.encode() + b"." + body, hashlib.sha256).hexdigest()
```

## 4. 보안·개인정보

- 처리 대상은 자녀가 등록한 부모님 번호와의 통화뿐입니다. 나머지는 내용·번호를 저장하지 않습니다.
- 외부 LLM에는 전화번호·계좌번호를 가린 텍스트만 보내고, 화면·자녀 메신저 응답의 번호도 가립니다.
- 사칭 정황(상품권·송금·인증번호·'폰이 고장')은 LLM과 규칙 양쪽에서 잡고, 차단된 주문은 누가 승인해도 결제하지 않습니다.
- 결제를 대신 실행하는 에이전트에는 카드번호 대신 이 주문·이 금액에 30분 동안 한 번 쓰는 토큰만 넘깁니다.

## 5. SKT 기술이 들어가는 자리

| 기술 | 역할 | 지금 상태 |
| --- | --- | --- |
| 에이닷 통화 녹음·요약·할일 | 구매의 출발점 | 웹훅 계약 구현·시뮬레이터 제공 (SKT 협력 필요), 공유 1탭은 지금 가능 |
| A.X | 분석 엔진 (부탁 추출·상품 선택) | `OBA_AX_API_KEY`·`OBA_AX_BASE_URL`만 넣으면 1순위. 실패하면 다른 엔진·규칙 기반으로 자동 전환. 해커톤 때 A.X K2로 검증 |
| SK pay | 결제수단 | 데모의 두 번째 결제수단 — 카드가 거절되면 자동 복구 |
| 문자 | 엄마 안내 | 모의 발송. 발신번호 변작 금지에 맞춰 사전등록 서비스 번호 + 자녀 이름으로 설계 |

## 6. 지금 바로 되는 연결: 에이닷 공유 → iOS 단축어

SKT 협력 없이도 1탭으로 같은 처리를 탈 수 있습니다.

1. **단축어** 앱 → `+` → 이름 `oba로 보내기` → ⓘ에서 **공유 시트에서 보기** 켜기 (받는 유형: 텍스트·파일)
2. 동작 **URL 콘텐츠 가져오기** — URL `https://<서버>/v1/calls`, 방법 `POST`, 헤더 `Authorization: Bearer <가족 업로드 토큰>`(대시보드에 표시), 요청 본문 **양식**: 파일 `file` = 단축어 입력
3. 통화 후 에이닷 통화 기록 → **공유** → **oba로 보내기**

엄마 문자도 단축어 **자동화 → 메시지(보낸 사람: 엄마) → 즉시 실행**으로 `caller_number`와 함께 보내면, 등록된 번호가 아닐 때 서버가 버립니다.

## 7. 함께 정하고 싶은 것

- 에이닷 쪽 동의 화면과 '가족 부탁 위임' 설정 위치, 동의 철회 시 통지 방식
- 웹훅 대신 파트너가 가져가는 방식(풀)을 원하시면 같은 계약으로 `GET` 엔드포인트를 맞출 수 있습니다
- 할일 데이터의 형식(카테고리·품목 구조)이 있다면 그대로 받아 추출 정확도를 높일 수 있습니다
- A.X 파트너 엔드포인트·모델명, 문자 발송·SK pay 테스트 환경
